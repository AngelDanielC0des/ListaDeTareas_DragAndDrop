    Arrastra por el asa ⠿ para reordenar. Con el teclado: Ctrl + ↑ / ↓. Pulsa n para escribir una tarea nueva, / para buscar. o pulsa ?.

    Atajos de teclado

    n
    Escribir una tarea nueva
    /
    Buscar entre las tareas
    Ctrl + ↑ / ↓
    Mover la tarea, con el foco puesto en su asa
    Intro
    Confirmar la edición de una tarea
    Mayús + Intro
    Salto de línea dentro de una tarea
    Esc
    Cancelar la edición o cerrar esta ventana
    ?
    Abrir esta ayuda
